title: Introduction

A Rust translation library that reads the [nuxt-i18n-micro](https://github.com/s00d/nuxt-i18n-micro) locale
format and behaves like `@i18n-micro/core`: the same files, the same lookup through root and page chunks,
the same plurals, interpolation, linked messages and `Intl`-compatible formats. A Tauri plugin hands the
same catalog to `@i18n-micro` on the frontend, so a Tauri app keeps one set of locale files for Rust and JS.

| Package | What |
| --- | --- |
| [`i18n-next`](https://crates.io/crates/i18n-next) | the crate: catalog, pages, plurals, `Text`, `t!`, formats; native and wasm; no runtime dependencies |
| [`tauri-plugin-i18n-next`](https://crates.io/crates/tauri-plugin-i18n-next) | the Tauri 2 plugin: delivers chunks to the WebView, `set_locale` for all windows, native menu and tray labels |
| [`tauri-plugin-i18n-next-api`](https://www.npmjs.com/package/tauri-plugin-i18n-next-api) | the frontend: `connect` for any `@i18n-micro` instance (Vue, React, Preact, Solid, runtime), `/vue` with a router guard |

The three always share one version. A Rust frontend (Leptos, Yew, Dioxus) uses the crate itself: in the browser
with `remote` + `ensure_async`, inside Tauri with the `tauri-guest` feature.

## How it differs

- **One format for both sides.** JSON trees as in nuxt-i18n-micro, no FTL, no `.po`. A Nuxt site and a
  Tauri app can share the folder.
- **Root and page chunks.** Shared keys load once; page keys load per page. See [Pages](/guides/pages).
- **No IPC per key.** The frontend gets whole chunks over a custom protocol and resolves keys itself.
  See [Tauri](/guides/tauri).
- **Measured, not assumed.** A benchmark for every public function, allocation counts and instruction
  counts in CI. See [Performance](/performance).
- **Matches the JS library.** Golden files are written by the real `@i18n-micro/core` and `Intl` in Node;
  the Rust side must print the same lines. See [Compatibility](/compatibility).

## When to use it

- A Tauri app with `@i18n-micro/vue` (or any `@i18n-micro` adapter) that also needs translated menus,
  tray, notifications, errors and command results in Rust.
- A Rust service, CLI or wasm frontend (Leptos, Yew, Dioxus) that wants the nuxt-i18n-micro format.
- A Nuxt site and a desktop app built from the same locale files.

If you need Fluent's grammar features (selectors on gender, terms), use Fluent.
