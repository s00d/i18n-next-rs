A Rust translation library for the [nuxt-i18n-micro](https://github.com/s00d/nuxt-i18n-micro) locale format.
It reads the same JSON files and gives the same answers as `@i18n-micro/core`: root and page chunks, plurals,
parameters, linked messages and `Intl`-style number and date formats. In a Tauri app the plugin hands the same
catalog to `@i18n-micro` on the frontend, so Rust and JS share one set of locale files.

| Package | What |
| --- | --- |
| [`i18n-next`](https://crates.io/crates/i18n-next) | the crate: catalog, pages, plurals, `Text`, `t!`, formats; native and wasm |
| [`tauri-plugin-i18n-next`](https://crates.io/crates/tauri-plugin-i18n-next) | the Tauri 2 plugin: sends chunks to the WebView, switches the locale in every window, relabels native menus and tray |
| [`tauri-plugin-i18n-next-api`](https://www.npmjs.com/package/tauri-plugin-i18n-next-api) | the frontend: `connect` for any `@i18n-micro` instance, `/vue` with a router guard |

The three packages always share one version.

## When to use it

- A Tauri app with `@i18n-micro/vue` (or another `@i18n-micro` adapter) that also needs translated menus, tray,
  notifications, errors and command results in Rust.
- A Rust service, CLI or wasm frontend (Leptos, Yew, Dioxus) that wants the nuxt-i18n-micro format.
- A Nuxt site and a desktop app built from the same locale files.
