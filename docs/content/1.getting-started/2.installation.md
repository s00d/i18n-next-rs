## Rust

```toml [Cargo.toml]
[dependencies]
i18n-next = "0.1"
```

MSRV is Rust 1.90, edition 2024. With the default features (`std`, `format`, `tz`, `global`) the crate has no
runtime dependencies.

| Feature | Default | What |
| --- | --- | --- |
| `format` | yes | `tn` / `td` / `tdr`, named formats, formatted arguments in `Text`, CLDR data |
| `tz` | yes | IANA time zones and the system zone; without it only UTC and fixed offsets |
| `global` | yes | `install`: the process-wide instance of `t!` / `tc!` / `key!` and the free functions |
| `serde` | no | `Serialize` for `Text` (a command or a handler returns it translated) |
| `tracing` | no | misses, loads and fetches as `tracing` events |
| `watch` | no | reload changed files in debug builds |
| `tauri-guest` | no | a Rust frontend inside Tauri, see [Tauri guest](/platforms/tauri-guest) |

The whole list, with sizes: [Features](/reference/features). `default-features = false` gives the micro build:
catalog, pages, templates, plurals and `Text` (123 KB of `.wasm`).

### CLDR data size

Number and date data are generated Rust statics. `I18N_NEXT_LOCALES` keeps only the locales you ship (their CLDR
parents and `en` are added); unset, the 425 CLDR `modern` locales are built in:

```bash
I18N_NEXT_LOCALES=en,de,ru cargo build --release
```

See [Formats](/guides/formats#cldr-data-and-i18n_next_locales) and the size table in
[Browser (wasm)](/platforms/browser-wasm#size).

## Tauri plugin

```toml [src-tauri/Cargo.toml]
[dependencies]
i18n-next = "0.1"
tauri-plugin-i18n-next = "0.1"
```

```json [src-tauri/capabilities/default.json]
{
  "identifier": "default",
  "windows": ["main"],
  "permissions": ["core:default", "i18n-next:default"]
}
```

Add `i18n-next:allow-report-missing` to a dev capability for the [missing-key report](/guides/tauri#missing-keys-in-dev).
An app with a Content Security Policy must allow the protocol, see [Tauri](/guides/tauri#content-security-policy).
The crate, the plugin and the npm package always share one version.

## Frontend

```bash
pnpm add tauri-plugin-i18n-next-api
pnpm add @i18n-micro/vue          # for tauri-plugin-i18n-next-api/vue
# or @i18n-micro/react, @i18n-micro/preact, @i18n-micro/solid, @i18n-micro/runtime with connect()
```

The package has no runtime dependency on `@i18n-micro/*`: `connect` takes any instance, and the `/vue` entry
uses the optional peers `@i18n-micro/vue` and `vue`.

## Rust frontend in the browser

```toml [Cargo.toml]
[dependencies]
i18n-next = "0.1"                                             # remote + ensure_async
# i18n-next = { version = "0.1", features = ["tauri-guest"] } # the same app inside Tauri
```

The crate brings no HTTP client and no `web-sys`: the fetch is yours. See [Browser (wasm)](/platforms/browser-wasm).

## `i18n.json`

Locales and formats live in one file next to the locale folder, not inside it. Rust, the plugin and a Nuxt
site read the same file. See [i18n.json](/reference/i18n-json).
