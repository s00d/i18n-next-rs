## Rust

```toml [Cargo.toml]
[dependencies]
i18n-next = "0.1"
```

MSRV is Rust 1.90, edition 2024.

| Feature | Default | What |
| --- | --- | --- |
| `format` | yes | `tn` / `td` / `tdr`, formatted arguments in `Text`, CLDR data for formats |
| `tz` | yes | IANA time zones and the system zone; without it only UTC and fixed offsets |
| `tzdb` | Windows only | built-in compact tzdb where the OS has no TZif files |
| `global` | yes | global instance, `t!` / `tc!` / `tn!` / `td!` / `tdr!` / `key!`, `scope` |
| `std` | yes | without it, `no_std` + `alloc` if that makes the micro build smaller |
| `serde` | no | `Serialize` for `Text` and `Key` (the plugin turns it on) |
| `currency-names` | no | currency names for `currencyDisplay: name` |
| `chrono`, `time` | no | `From<…>` for dates |
| `watch` | no | reload changed files in debug builds |
| `tracing` | no | misses and loads as `tracing` events |
| `tauri-guest` | no | a Rust frontend inside Tauri, see [Tauri guest](/platforms/tauri-guest) |

`default-features = false` gives the micro build: catalog, pages, templates, plurals, `t!` and `Text`.

### CLDR data size

CLDR data is generated Rust statics. `I18N_NEXT_LOCALES` keeps only the locales you ship (parent locales
are added automatically):

```bash
I18N_NEXT_LOCALES=en,de,ru cargo build --release
```

## Tauri plugin

```toml [src-tauri/Cargo.toml]
[dependencies]
tauri-plugin-i18n-next = "0.1"
```

Add `i18n-next:default` to your capability. The plugin, the crate and the npm package always share one
version.

## Frontend

```bash
pnpm add tauri-plugin-i18n-next-api
pnpm add @i18n-micro/vue   # only for tauri-plugin-i18n-next-api/vue
```

## `i18n.json`

Locales and formats live in one file next to the locale folder, not inside it. Rust, the plugin and a Nuxt
site read the same file. See [Locale files](/guides/locale-files#i18njson).
