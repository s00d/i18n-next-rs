::

## Rust

```
locales/
  en.json
  ru.json
  pages/settings/en.json
  pages/settings/ru.json
```

```rust [main.rs]
use i18n_next::{I18n, t};

fn main() -> Result<(), i18n_next::Error> {
    I18n::builder().dir("locales").locale("ru").fallback("en").install()?;

    println!("{}", t!("nav.home"));
    println!("{}", t!("cart.summary", name = "Ann", count = 3));
    println!("{}", t!("title", @page = "settings"));
    Ok(())
}
```

`install` sets the global instance once per process; `t!` reads it from anywhere.
See [Global access and scope](/guides/global-and-scope).

## Tauri + Vue

```rust [src-tauri/src/lib.rs]
let i18n = I18n::builder().config("../i18n.json").dir("../locales").build()?;

tauri::Builder::default()
    .plugin(tauri_plugin_i18n_next::Builder::new(i18n).build())
    .run(tauri::generate_context!())?;
```

```ts [src/main.ts]
import { createApp } from 'vue'
import { createTauriI18n } from 'tauri-plugin-i18n-next-api/vue'

const app = createApp(App).use(router)
app.use(await createTauriI18n({ router }))
app.mount('#app')
```

```vue [Cart.vue]
<i18n-t keypath="cart.total" :number="sum" />
```

The router guard loads the page chunk before each navigation finishes, so raw keys never flash.
`setLocale` switches Rust and every window. See [Tauri](/guides/tauri) and [Frontend](/guides/frontend).
