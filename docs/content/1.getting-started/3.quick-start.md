## Rust

```
locales/
  en.json
  ru.json
  pages/settings/en.json
  pages/settings/ru.json
```

```rust [main.rs]
use i18n_next::{I18n, t};

fn main() -> Result<(), i18n_next::Error> {
    I18n::builder()
        .config("i18n.json")          // optional: locales, defaultLocale, fallbackLocale
        .dir("locales")
        .locale("ru")
        .fallback("en")
        .install()?;                  // build + the global instance

    println!("{}", t!("nav.home"));
    println!("{}", t!("greeting", name = "Ann"));
    println!("{}", t!("title", @page = "settings"));
    i18n_next::set_locale("en")?;
    Ok(())
}
```

`t!` returns a lazy `Text`: it is resolved when shown, so a stored one follows `set_locale`.
Without the global instance, pass one: `i18n.text("nav.home")` or `t!(i18n => "nav.home")`.
`I18n` is an `Arc` inside: clone it into threads and tasks. See [Text](/guides/text) and
[Global access and scope](/guides/global-and-scope).

## Tauri + Vue

```rust [src-tauri/src/lib.rs]
let i18n = I18n::builder()
    .config("../i18n.json")
    .dir("../locales")                              // mobile: .files([...]) with include_bytes!
    .missing(tauri_plugin_i18n_next::missing)       // dev report of missing keys
    .build()?;

tauri::Builder::default()
    .plugin(tauri_plugin_i18n_next::Builder::new(i18n).build())   // installs it: t! works in Rust
    .run(tauri::generate_context!())?;
```

Add `i18n-next:default` to the capability ([Installation](/getting-started/installation#tauri-plugin)).

```ts [src/main.ts]
import { createApp } from 'vue'
import { createTauriI18n } from 'tauri-plugin-i18n-next-api/vue'

const app = createApp(App).use(router)
app.use(await createTauriI18n({ router }))
app.mount('#app')
```

```vue [Cart.vue]
<i18n-t keypath="cart.total" :number="sum" />
```

The router guard loads the page chunk before each navigation finishes, so raw keys never flash.
`setLocale` switches Rust and every window. See [Tauri](/guides/tauri) and [Frontend](/guides/frontend).

## Rust frontend (Leptos)

The same files, fetched by the app. `examples/leptos-app` is a complete Leptos CSR app built this way:

```rust [src/main.rs]
use i18n_next::{I18n, t};

const FILES: [&str; 4] = ["en.json", "ru.json", "pages/settings/en.json", "pages/settings/ru.json"];

async fn start() -> Result<(), i18n_next::Error> {
    let i18n = I18n::builder()
        .config_json(include_str!("../i18n.json"))
        .remote(FILES)                                // the paths are known, the bytes come later
        .build()?;
    i18n.ensure_async(&i18n.locale(), None, fetch).await?;   // fetch: your `async fn(String) -> Result<Vec<u8>, E>`
    i18n_next::install(i18n)?;
    Ok(())
}

// in components
view! { <h1>{t!("greeting", name = "Leptos").to_string()}</h1> }
```

Inside Tauri the same app connects to the plugin instead (feature `tauri-guest`):

```rust
let i18n = i18n_next::tauri_guest::connect("index").await?;   // meta + chunks over i18n-next://
i18n_next::install(i18n)?;
i18n_next::tauri_guest::set_locale("de").await?;              // Rust, native labels, every window
```

See [Browser (wasm)](/platforms/browser-wasm) and [Tauri guest](/platforms/tauri-guest).
