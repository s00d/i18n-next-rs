## Format

A locale file is a JSON tree of any depth. Keys are paths joined with dots.

```json [locales/en.json]
{
  "nav": { "home": "Home", "settings": "Settings" },
  "cart": {
    "summary": "{name} has {count} item | {name} has {count} items"
  },
  "pair": "{0} and {1}",
  "list": ["first", "second"]
}
```

| Rule | Example |
| --- | --- |
| Nested objects become dotted keys | `nav.home` |
| A literal flat key beats walking the tree | `"a.b": "x"` wins over `{ "a": { "b": "y" } }` |
| Array items are addressed by index | `list.0` |
| `null` means "no value" | the lookup goes on to the next layer |
| `__proto__` is ignored | never becomes a key |
| A UTF-8 BOM is allowed | |

A broken file is an error with its path (in JS it is a warning and the file is skipped).

## Layout

```
locales/
  en.json                      root chunk of en
  de.json
  pages/settings/en.json       page chunk "settings"
  pages/user/profile/en.json   page chunk "user-profile"
```

- `locales/<locale>.json` is the root (global) chunk: menus, buttons, errors, tray.
- `locales/pages/<a>/<b>/<locale>.json` is the page chunk of route `a-b`, as in Nuxt.
- Other nested files are ignored. Files load in order of their relative path.

How root and page chunks combine: [Pages](/guides/pages).

## `i18n.json`

One config for Rust, the Tauri frontend and Nuxt. It sits next to the locale folder, **not inside it**:
the loader treats every `*.json` in the folder root as a locale.

```jsonc [i18n.json]
{
  "defaultLocale": "en",
  "fallbackLocale": "en",
  "locales": [
    { "code": "en", "iso": "en-US", "displayName": "English" },
    { "code": "de-at", "iso": "de-AT", "fallbackLocale": "de" },
    { "code": "ar", "iso": "ar", "dir": "rtl" },
    { "code": "es", "disabled": true }
  ],
  "numberFormats": { "en": { "currency": { "style": "currency", "currency": "USD" } } },
  "datetimeFormats": { "en": { "short": { "dateStyle": "short" } } }
}
```

| Field | Effect |
| --- | --- |
| `locales[].iso` | tag for plurals and formats |
| `locales[].fallbackLocale` | adds a step to the fallback chain |
| `locales[].dir` | sent to the frontend, sets `<html dir>` |
| `locales[].disabled` | hidden from `available_locales`, `set_locale` refuses it |
| `locales[].displayName` | defaults to the CLDR autonym ("Deutsch") |
| `numberFormats`, `datetimeFormats` | named formats, as in Vue I18n |

Rust reads it with `.config("i18n.json")` or `.config_json(include_str!(…))`. Builder calls (`iso`,
`fallback_for`, `formats`) override the file. Lands in M1 (Rust) and M7 (plugin).
