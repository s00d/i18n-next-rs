---
title: Global access and scope
description: install, the t! family of macros, key! constants and scope for a request or task.
---

Create the instance once, then call `t!("key")` anywhere: handlers, `Display` of errors, Tauri commands,
CLIs. The Tauri plugin installs it for you (M7).

```rust
I18n::builder().dir("locales").locale("ru").fallback("en").install()?;   // once per process
// or: i18n_next::install(i18n.clone())?;
```

A second `install` returns `Error::AlreadyInstalled`. The instance itself is mutable (`set_locale`,
`reload`, `add_messages`), so there is nothing to replace. `global()` returns it (`Option`).

Functions for those who prefer them: `i18n_next::t("key")` (a `Text`), `set_locale("de")`, `locale()`,
`page("settings")` (a `View`). They act on the instance `t!` would use.

## Macros

```rust
use i18n_next::{t, tc, key};

t!("welcome", name = user.name.clone());
t!("cart.summary", name = "Ann", count = n);   // count = the plural, as tc
t!("pair", ["Ann", "Bob"]);                    // {0} {1}
t!("title", @page = "settings");
t!("title", @locale = "de", @or = "Title");
t!("terms", @html);
tc!("apples", 5);                              // t!("apples", count = 5)

t!(i18n => "nav.home");                        // explicit instance or view, same grammar
```

Every macro returns a lazy [`Text`](/guides/text). Options take `@` so a `{page}` parameter stays a
parameter; an explicit instance is separated by `=>`. `@number`, `@date` and `@relative` are reserved
for the formatting stages (M5, M6) and do not compile yet.

## `key!`

```rust
const QUIT: Key = key!("menu.quit");     // const, allocates nothing
println!("{QUIT}");                      // resolved now, through scope and the global instance
QUIT.args().arg("app", "Demo");          // a Text

#[derive(thiserror::Error, Debug)]
enum AppError {
    #[error("{}", key!("errors.not_found"))] NotFound,
    #[error("{}", t!("errors.io", path = .0.display().to_string()))] Io(std::path::PathBuf),
}
```

## `scope`

Locale, page and instance per request or task, without passing them down (`run(locale, fn)` of
`@i18n-micro/node`):

```rust
i18n_next::scope().locale("de").page("checkout").run(|| render());
i18n_next::scope().instance(test_i18n).run(|| assert_eq!(t!("a"), "A"));   // tests, libraries

// any async runtime: the frame is set for each poll and removed after
async fn locale_mw(req: Request, next: Next) -> Response {
    let accept = req.headers().get("accept-language").and_then(|v| v.to_str().ok()).unwrap_or("");
    let lang = i18n_next::negotiate(accept, ["en", "de", "ru"]).unwrap_or_else(|| "en".into());
    i18n_next::scope().locale(lang).wrap(next.run(req)).await
}
```

A text without its own instance, locale or page takes each from the nearest frame that sets it; an
inner frame overrides one part and inherits the rest. `.locale` / `.page` on the `Text` (or `@locale`
/ `@page`, or a `View`) beat the scope; an explicit instance beats the scope's. Without any instance
the key is shown, with one warning on stderr in debug builds. Frames are popped in `Drop`: a panic
leaves the stack as it was.

`wrap` boxes the future once and costs a thread-local push and pop per poll; it needs no runtime and
no task-local, so it works with tokio, smol, `wasm-bindgen-futures` or Tauri's runtime.

`negotiate(header, available)` takes an `Accept-Language` header or a comma-separated list
(`navigator.languages`): entries by `q`, `de-AT` → `de-at`, then `de`, then any `de-*` (one with
the same script first: `zh-Hant-TW` → `zh-hant-hk` over `zh-hans`); case and `_` do not matter. A
tag with `q=0` is refused: never chosen, not through `*`, shortening or the same-language step. An
entry with a malformed weight (`q=2`, `q = 0.5`, another parameter) is dropped, as RFC 9110 reads
it. It returns the code as `available` spells it.
