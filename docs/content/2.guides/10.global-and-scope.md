---
title: Global access and scope
description: install, the t! family of macros, key! constants and scope for a request or task.
---

::note
Lands in M4.
::

Create the instance once, then call `t!("key")` anywhere: handlers, `Display` of errors, Tauri commands,
CLIs. The Tauri plugin installs it for you.

```rust
I18n::builder().dir("locales").locale("ru").fallback("en").install()?;   // once per process
```

A second `install` returns `Error::AlreadyInstalled`. The instance itself is mutable (`set_locale`,
`reload`, `add_messages`), so there is nothing to replace.

## Macros

```rust
use i18n_next::{t, tc, tn, td, tdr, key};

t!("welcome", name = user.name);
t!("cart.summary", name = user.name, count = n);
t!("title", @page = "settings");
t!("title", @locale = "de", @or = "Title");
t!("terms", @html);
tc!("apples", 5);
tn!(9.99, "currency"); td!(at, "short"); tdr!(at);

t!(i18n => "nav.home");                  // explicit instance, same grammar
```

Options take `@` so a `{page}` parameter stays a parameter; an explicit instance is separated by `=>`.

## `key!`

```rust
const QUIT: Key = key!("menu.quit");     // const, allocates nothing
println!("{QUIT}");                      // resolved in the current locale

#[derive(thiserror::Error, Debug)]
enum AppError {
    #[error("{}", key!("errors.not_found"))] NotFound,
}
```

## `scope`

Locale and page per request or task, without passing them down:

```rust
i18n_next::scope().locale("de").page("checkout").run(|| render());
let fut = i18n_next::scope().locale(lang).wrap(async { handler(req).await });
```

`wrap` sets the scope for each poll, so it works with any async runtime. A macro without `=>` resolves:
the nearest `scope`, then the global instance, then (no `install`) the key as text with one warning in
debug builds. `@locale` / `@page` in the call beat the scope.
