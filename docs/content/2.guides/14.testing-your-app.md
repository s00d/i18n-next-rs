---
title: Testing your app
description: An instance per test with scope().instance, a fixed clock and zone.
---

Tests should not share the global instance. Give each test its own:

```rust
let i18n = I18n::builder()
    .messages("en", None, json!({ "a": "A" }))
    .time_zone("UTC")
    .clock(|| fixed_now)
    .build()?;

i18n_next::scope().instance(i18n).run(|| {
    assert_eq!(t!("a").to_string(), "A");
});
```

- `scope().instance` affects only this thread or task, so tests run in parallel.
- A fixed `clock` and zone make `td` / `tdr` output stable: `time_zone` replaces the system zone
  (`TZ`, `/etc/localtime`, the browser's), `clock` the system clock (`tdr` reads it on every call).
- A clock you can move tests relative dates without waiting: share an `AtomicI64`.

```rust
use std::sync::{Arc, atomic::{AtomicI64, Ordering}};

let now = Arc::new(AtomicI64::new(1_704_428_640_000));
let clock = now.clone();
let i18n = I18n::builder().clock(move || clock.load(Ordering::SeqCst)).build()?;
let seen = i18n.text("seen").relative(1_704_428_640_000i64);  // "Seen {relativeDate}"
now.fetch_add(3 * 86_400_000, Ordering::SeqCst);
assert_eq!(seen.to_string(), "Seen 3 days ago");           // the same Text, the new now
```

- `assert!(i18n.check().is_clean())` catches missing keys and broken placeholders; see [Checks](/guides/checks).
