## `check()`

```rust
let report = i18n.check();
assert!(report.is_clean(), "{report}");
```

It reports:

- keys missing in a locale compared to `defaultLocale`;
- `{placeholders}` that differ between locales of one key;
- plural form counts that do not match the locale's CLDR categories;
- broken linked messages;
- pages without a file in some locales.

## Typed keys

- Frontend: `@i18n-micro/types-generator` (see [Frontend](/guides/frontend#typed-keys)).
- Rust (M11): `i18n_next::build::keys("locales", out_dir)` in your `build.rs` generates `Key` constants;
  a typo becomes a compile error.

## CLI

`@i18n-micro/cli` (`check`, `lint`, `translate`, export / import) works on the same files.
