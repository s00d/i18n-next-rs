---
title: Tracing
description: Misses, loads, reloads and fetches as tracing events with the tracing feature.
---

```toml [Cargo.toml]
i18n-next = { version = "0.1", features = ["tracing"] }
```

```rust
tracing_subscriber::fmt().with_max_level(tracing::Level::DEBUG).init();
let i18n = I18n::builder().dir("locales").build()?;   // "i18n-next: load" per file
i18n.t("nope");                                         // WARN i18n-next: missing translation locale="en" page="index" key="nope"
```

| Event | Level | Fields |
| --- | --- | --- |
| `i18n-next: missing translation` | `warn` | `locale`, `page` (`index` for the root), `key` |
| `i18n-next: missing format, default options used` | `warn` | `kind` (`number` / `datetime`), `name`, `locale` |
| `i18n-next: load failed` | `warn` | `error`: a lazy file that cannot be read (its layer stays empty) |
| `i18n-next: load` | `debug` | `path`, `bytes`, `micros`: a file read at `build`, or a lazy file on first use |
| `i18n-next: add_file` | `debug` | `path`, `bytes`, `micros`: a remote file added (`add_file`, `ensure_async`) |
| `i18n-next: reload` | `debug` | `path` (always `""`), `bytes` (always `0`), `micros`: one `reload` of the whole catalog |
| span `i18n_next::ensure` | `debug` | `path`: one fetch of `ensure_async` |

`micros` is `0` on `wasm32-unknown-unknown` (no monotonic clock there). The `missing` handler of the builder is
called as well; tracing does not replace it.

Without the feature nothing is emitted, with two exceptions in debug builds: a lazy file that cannot be read and a
named format that is nowhere to be found are written to stderr (as JS warns), since there is no caller to hand
the error to.

In a Tauri app the dev report is often more useful for misses: see [Tauri](/guides/tauri#missing-keys-in-dev).
