---
title: Parameters
description: Named and positional placeholders, Arg, and a translation inside a translation.
---

```json
{ "welcome": "Hello, {name}!", "pair": "{0} and {1}", "hello": "Hi, {who}" }
```

```rust
t!("welcome", name = user.name.clone());
t!("pair", ["Ann", "Bob"]);
t!("hello", who = i18n.text("user.guest"));          // nested translation
t!("errors.io", path = Arg::display(p.display()));   // any Display, formatted now
t!("kw", r#type = "a");                              // raw identifier: fills {type}
t!("due", when = Arg::date_as(d, "short"));          // formatted argument
```

- A placeholder is `{name}` with no spaces or braces inside; `{0}` takes an item of an array argument.
- A placeholder without a value stays in the text as is, like in JS.
- Templates are tokenized once at load, never per call.
- Plain numbers are inserted as `String(value)` would. Only explicit `number` / `date` / `relative`
  arguments are localized; see [Formats](/guides/formats).

Conversions into `Arg`: `&str`, `String`, `&String`, `Arc<str>`, `Box<str>`, `Cow<str>`, `char`,
integers, `f32` / `f64`, `bool`, `Text`, `Key`; any other `Display` value through `Arg::display`
(formatted when the argument is made). Integers past ±2^53 from `u64`, `u128` and `i128` show what
JS would hold, the nearest `f64` (`2^53 + 1` → `9007199254740992`, `1e+21` and up with an exponent),
as a `Count` does; `u128` / `i128` need the `format` feature.

A nested translation (`Text` or `Key` as an argument) is resolved each time the outer one is
shown. Without its own locale, page or instance it takes the outer text's (its own, else the
scope's), the way an inner `<i18n-t>` inherits: `i18n.text("outer").locale("de").arg("x",
i18n.text("inner"))` shows `inner` in German. Under `html` a plain nested text is escaped and an
`html` one is inserted as is (its own arguments are escaped once). `missing` is called once per
display for the outer and the inner text alike. Nesting stops at 64 levels: a deeper `Text`
argument is dropped and its placeholder shows as written.

`Arg` variants: `Str`, `String`, `Int`, `Float`, `Bool`, `Null`, `Text`, `Number { value, format }`
and `Date`, built by `Arg::date(at)`, `Arg::date_as(at, "name")` and `Arg::relative(at)` (formatted when
shown, in the outer text's instance and locale, like `td` / `tdr`).
