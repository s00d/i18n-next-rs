---
title: Plurals
description: Forms separated by |, index and CLDR-category rules, the =0 marker and iso tags.
---

::note
Lands in M2.
::

```json
{ "apples": "no apples | one apple | {count} apples" }
```

```rust
tc!("apples", 5);
t!("apples", count = 5);
```

The rule is a literal port of `pluralForm` from `@i18n-micro/core`:

- forms are separated by ` | `;
- when the number of forms matches the CLDR categories of the locale ("unmarked"), the form is picked by
  category (`one`, `few`, `many`, `other`…);
- otherwise the index rule applies;
- a form starting with `=0 ` is used for zero;
- the locale's tag comes from `iso` (`.iso("ua", "uk-UA")` or `i18n.json`); an unknown tag uses the index
  rule.

Plural rules are generated from CLDR 48 `plurals.json` into Rust code and checked against
`Intl.PluralRules` for every locale. They are always compiled in: a few KB.
