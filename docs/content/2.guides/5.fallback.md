---
title: Fallback and missing keys
description: Fallback chains, the missing handler and try_t.
---

::note
Lands in M1.
::

```rust
I18n::builder()
    .locale("de-at")
    .fallback("en")                 // global fallback: the weakest layer
    .fallback_for("de-at", "de")    // de-at → de → en
    .missing(|locale, key, page| eprintln!("missing {locale}/{page:?}/{key}"))
    .build()?;
```

- Each locale has a chain, as in Nuxt: `de-at → de → en`. The global fallback is always last.
- A miss returns the default value if one is given (`@or` / `.or()`), else the key itself, and calls
  `missing(locale, key, page)`.
- `try_t` returns `None` instead of the key; `has` only checks.

In a Tauri dev build the plugin also collects misses from the frontend; see [Tauri](/guides/tauri#missing-keys-in-dev).
