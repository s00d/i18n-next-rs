---
title: Linked messages
description: "@:key references with upper, lower and capitalize modifiers, resolved at load."
---

::note
Lands in M3.
::

```json
{
  "brand": "acme",
  "title": "Welcome to @:brand",
  "shout": "@.upper:brand",
  "quoted": "@:{'nav.home'}"
}
```

```rust
I18n::builder().linked_messages(true).dir("locales").build()?;
```

- Opt-in, as in `@i18n-micro/core`.
- Forms: `@:key`, `@.upper:key`, `@.lower:key`, `@.capitalize:key`, `@:{'key'}`.
- Resolved once at load, so lookups cost nothing extra. A broken link is reported by
  [`check()`](/guides/checks).
