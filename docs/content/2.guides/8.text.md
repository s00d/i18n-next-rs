---
title: Text
description: The lazy translated value, the Rust counterpart of <i18n-t>.
---

::note
Lands in M4.
::

`Text` is one chain with options mirroring the props of `<i18n-t>`. It is resolved each time it is shown,
so a `Text` stored in UI state shows the new language after `set_locale`.

```rust
let total = i18n.text("cart.total")
    .arg("name", &user.name)
    .count(items.len())                 // plural → {count}
    .number_as(sum, "currency")         // {number}
    .date_as(at, "short")               // {date}
    .relative(at)                       // {relativeDate}
    .or("Total")                        // defaultValue
    .hide_if_empty()
    .page("checkout").locale("de");

println!("{total}");                    // Display
total.resolve();                        // Option<String>: None on a miss or hide_if_empty
total.html();                           // arguments escaped, the translation is trusted
```

| `<i18n-t>` prop | `Text` |
| --- | --- |
| `keypath` | `i18n.text(key)` |
| `params` | `.arg(name, value)` |
| `plural` | `.count(n)` |
| `number`, `date`, `relativeDate` | `.number` / `.date` / `.relative` (+ `_as` for named formats) |
| `defaultValue` | `.or(..)` |
| `hideIfEmpty` | `.hide_if_empty()` |
| `customPluralRule` | `.plural_rule(..)` |
| `html` | `.html()` |

- `Display` writes straight into the formatter; `write_to` appends to your buffer without allocating.
- With the `serde` feature, `Text` serializes as the translated string, so a Tauri command or an axum
  handler can return it.
- `Text` is `'static + Send + Sync + Clone`.

For slots, see [Rich text](/guides/rich-text).
