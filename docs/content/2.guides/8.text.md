---
title: Text
description: The lazy translated value, the Rust counterpart of <i18n-t>.
---

`Text` is one chain with options mirroring the props of `<i18n-t>`. Nothing is looked up until it is
shown, and it is resolved again each time: a `Text` stored in UI state shows the new language after
`set_locale`, and the locale of the [scope](/guides/global-and-scope) it is shown in.

```rust
let total = i18n.text("cart.total")     // or t!("cart.total", …), View::text, Key::args
    .arg("name", user.name.clone())     // {name}: text, numbers, bools, another Text
    .count(items.len())                 // plural form, {count}
    .or("Total")                        // shown on a miss
    .hide_if_empty()
    .page("checkout")
    .locale("de");

println!("{total}");                    // Display, straight into the formatter
total.to_string();                      // one allocation
total.resolve();                        // Option<String>: None on a miss without .or, or hidden
total.write_to(&mut buf)?;              // into your buffer, no allocation
assert_eq!(total, "Gesamt: 3");         // == &str, for tests
```

| `<i18n-t>` prop | `Text` |
| --- | --- |
| `keypath` | `i18n.text(key)`, `t!(key)` |
| `params` | `.arg(name, value)`, `.args([a, b])` for `{0}`, `{1}` |
| `plural` | `.count(n)` |
| `defaultValue` | `.or(..)` |
| `hideIfEmpty` | `.hide_if_empty()` |
| `customPluralRule` | `.plural_rule(\|ctx\| ..)` |
| `html` | `.html()` |
| `number`, `date`, `relativeDate` | `.number` / `.date` / `.relative`: M5 and M6 |

How it resolves, as `resolveText` in `@i18n-micro/core`:

- The key's text in the locale and page: set on the `Text`, else the nearest scope's, else the active
  locale and the root. Page layer, then root, down the fallback chain.
- `.count(n)` picks the form `tc` picks and fills `{count}`; the count wins over an argument named `count`.
- A miss calls `missing` and shows the `.or` default, else the key. Both are interpolated, so
  `"Hello {name}"` as a key still shows the name. A subtree shows the key, as `t` does (JS prints
  `[object Object]`).
- `.html()` escapes text arguments (`&<>"'`); numbers and booleans stay as they are. The translation
  is trusted markup; a key standing in for a missing one is escaped, it may come from a request.
- `.hide_if_empty()`: blank text (JS `trim`) resolves to `None` and displays as the `.or` default, or
  nothing, the way `<i18n-t>` renders it.
- `.plural_rule(|ctx| ..)` replaces the plural rule when a count is set: its answer is the text as is;
  `None` is empty. `ctx.key`, `ctx.count`, `ctx.locale`, `ctx.get(key)` for the raw text.

Arguments are stored inline up to four: building a `Text` allocates nothing. A `Text` argument takes
owned or `'static` values (`&String` is copied); for borrowed parameters without a `Text`, `t_with`
with `Args` borrows.

With the `serde` feature, `Text` serializes as the displayed string, so a Tauri command or an axum
handler can return it. `Text` is `'static + Send + Sync + Clone`.

For slots, see [Rich text](/guides/rich-text).
