::note

::

The counterpart of `foldTemplate` and `<i18n-t>` slots: `"I accept the {link} and the {policy}"`.

```rust
let pieces: Vec<Widget> = i18n.text("terms").fold(
    |text| Widget::label(text),
    &[("link", &|| Widget::link("terms", URL)), ("policy", &|| Widget::link("policy", URL2))],
);
```

`fold` walks the template once: a placeholder with a slot becomes the slot's node, otherwise its
argument (or the placeholder as written) joins the surrounding text, which your closure turns into a
node. A slot wins over an argument of the same name. Empty runs are skipped.

```rust
for part in i18n.text("terms").arg("who", "Ann").parts() {
    match part {
        Part::Text(s) => { /* plain text, arguments filled in */ }
        Part::Slot(name) => { /* a placeholder no argument fills: your widget */ }
    }
}
```

Both read the same resolution as `Display` (locale, page, plural form, `html`, `hide_if_empty`). The
crate depends on no UI framework; `fold` and `parts` work with any of them.
