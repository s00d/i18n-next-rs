The counterpart of `foldTemplate` and `<i18n-t>` slots: `"I accept the {link} and the {policy}"`.

```rust
let pieces: Vec<Widget> = i18n.text("terms").fold(
    |text| Widget::label(text),
    &[("link", &|| Widget::link("terms", URL)), ("policy", &|| Widget::link("policy", URL2))],
);
```

`fold` walks the template once: a placeholder with a slot becomes the slot's node, otherwise its
argument (or the placeholder as written) joins the surrounding text, which your closure turns into a
node. A slot wins over an argument of the same name. Empty runs are skipped.

```rust
for part in i18n.text("terms").arg("who", "Ann").parts() {
    match part {
        Part::Text(s) => { /* plain text, arguments filled in */ }
        Part::Slot(name) => { /* a placeholder no argument fills: your widget */ }
    }
}
```

Both read the same resolution as `Display` (locale, page, plural form, `html`, `hide_if_empty`). The
crate depends on no UI framework; `fold` and `parts` work with any of them.

## Recipes

The JSON message is `"terms": "I accept the {link} and the {policy}."` in each.

### Leptos

```rust
use leptos::prelude::*;

let nodes: Vec<AnyView> = t!("terms").fold(
    |text| text.to_owned().into_any(),
    &[
        ("link", &|| view! { <a href="/terms">{t!("terms_link").to_string()}</a> }.into_any()),
        ("policy", &|| view! { <a href="/privacy">{t!("policy_link").to_string()}</a> }.into_any()),
    ],
);
view! { <p>{nodes}</p> }
```

Build the nodes inside the component's reactive closure so they are folded again after a locale switch.

### egui

```rust
ui.horizontal_wrapped(|ui| {
    for part in t!("terms").parts() {
        match part {
            Part::Text(s) => { ui.label(s.as_ref()); }
            Part::Slot(name) if name == "link" => { ui.hyperlink_to(t!("terms_link").to_string(), TERMS_URL); }
            Part::Slot(name) if name == "policy" => { ui.hyperlink_to(t!("policy_link").to_string(), PRIVACY_URL); }
            Part::Slot(_) => {}
        }
    }
});
```

### ratatui

```rust
use ratatui::text::{Line, Span};
use ratatui::style::Stylize;

let line = Line::from(t!("terms").fold(
    |text| Span::raw(text.to_owned()),
    &[("link", &|| "terms".underlined()), ("policy", &|| "privacy policy".underlined())],
));
```

### askama and other templates

`Text` is `Display`, so a template engine prints it as is: `{{ title }}` with `title: Text` in the context. For
markup in the message, build it with `.html()` (arguments are escaped, the translation is trusted) and mark it safe:
`{{ terms|safe }}`. Slots are not needed there: a nested `html` text argument is inserted as is, so
`i18n.text("terms").html().arg("link", i18n.text("terms_link_html").html())` gives the whole markup; plain string
arguments are escaped. Or render `parts()` in a loop.
