::note
Lands in M4. Recipes for egui, ratatui, Leptos and askama land in M10.
::

The counterpart of `foldTemplate` and `<i18n-t>` slots: `"I accept the {link} and the {policy}"`.

```rust
let pieces: Vec<Widget> = i18n.text("terms").fold(
    |text| Widget::label(text),
    &[("link", &|| Widget::link("terms", URL)), ("policy", &|| Widget::link("policy", URL2))],
);

for part in i18n.text("terms").parts() {
    match part {
        Part::Text(s) => { /* plain text */ }
        Part::Slot(name) => { /* your widget */ }
    }
}
```

The crate depends on no UI framework; `fold` and `parts` work with any of them.
