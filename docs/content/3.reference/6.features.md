## `i18n-next`

Default: `std`, `format`, `tz`, `global`.

| Feature | Default | What it brings |
| --- | --- | --- |
| `format` | yes | `tn` / `td` / `tdr`, named formats, `{number}` / `{date}` / `{relativeDate}` in `Text`, `f64` counts, CLDR number and date data |
| `tz` | yes | IANA time zones and the system zone ([Platforms](/platforms#time-zones)); without it dates show in UTC or a fixed offset |
| `tzdb` | no (Windows: on with `tz`) | a built-in tzdb as a fallback after the system's zones |
| `global` | yes | `install` and `global()`: the process-wide instance that `t!`, `Key` and the free functions fall back to; without it they read a `scope().instance(..)` or an explicit `t!(i18n => ..)` |
| `std` | yes | reserved; changes nothing today |
| `serde` | no | `Serialize` for `Text` (the displayed string), so a Tauri command or an HTTP handler can return them |
| `payload` | no | `i18n_next::payload`: the front-end payload the Tauri plugin sends and a Rust guest applies |
| `tauri-guest` | no | `i18n_next::tauri_guest` on `wasm32-unknown-unknown` (a [Rust frontend inside Tauri](/platforms#rust-frontend-inside-tauri)); elsewhere it is only `payload` |
| `watch` | no | `I18n::watch()`: reload `dir` / `lazy_dir` files on change, debug builds only, never on wasm |
| `tracing` | no | misses, loads and fetches as `tracing` events, see [Tracing](/guides/checks-and-tracing#tracing) |
| `currency-names` | no | plural currency names for `currencyDisplay: "name"` |
| `chrono`, `time` | no | `Timestamp` from `chrono::DateTime<Tz>` / `NaiveDateTime` (as UTC), `time::OffsetDateTime` / `UtcDateTime` / `PrimitiveDateTime` (as UTC) |

`default-features = false` is the micro build: catalog, pages, templates, plurals, `Text`, the macros with an
explicit instance and `scope`. Add `global` for `install`.

## `tauri-plugin-i18n-next`

| Feature | Default | What it brings |
| --- | --- | --- |
| `tray-icon` | no | `Relabel` for the tray icon's tooltip; turns on tauri's feature of the same name |

The plugin turns on `i18n-next`'s `payload`, `serde` and `watch`. It builds only for native targets.
