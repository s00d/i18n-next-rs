description: Targets and what is available on each.
---

The crate builds and is tested on every target from the first commit. The plugin is native only: Tauri
does not build for wasm.

| Target | Where | Differences |
| --- | --- | --- |
| desktop (Linux, macOS, Windows), Android, iOS | native, Tauri | everything available |
| `wasm32-unknown-unknown` | browser: Leptos, Yew, Dioxus, egui web, a Rust frontend in Tauri | no file system: `dir` / `lazy_dir` do not exist (`cfg`, not a runtime error); time and zone from `js-sys` |
| `wasm32-wasip1` / `wasip2` | WASI runtimes, edge | file system available, `dir` works |

The API is the same everywhere; your code needs no `cfg`.
