---
title: Desktop
description: Linux, macOS and Windows.
---

Everything is available. Time zone data comes from the OS (`/usr/share/zoneinfo`, `$TZDIR`) on Linux and
macOS. Windows has no TZif files, so the `tzdb` feature (on by default there) embeds a compact tzdb.

For release builds: `lto = "thin"`, `codegen-units = 1` and `I18N_NEXT_LOCALES` with the locales you ship.

CI runs the test suite on Linux, macOS and Windows with stable and Rust 1.90.
