---
title: Android
description: Embedded files instead of dir, and time zone data.
---

::note
Lands with the plugin in M7; the Android build of the Tauri playground in M10.
::

App resources on Android are not a regular file system, so embed the catalog:

```rust
static LOCALES: include_dir::Dir = include_dir::include_dir!("$CARGO_MANIFEST_DIR/../locales");
I18n::builder().files(walk(&LOCALES)).install()?;   // (path, bytes) pairs, same layout as on disk
```

Time zones are read from the system tzdata container (`/apex/com.android.tzdata/etc/tz/tzdata`).
The system locale comes from the WebView's `navigator.languages`.
