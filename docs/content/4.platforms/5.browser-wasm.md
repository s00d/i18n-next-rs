::note
The crate is built for wasm from M0; `ensure_async` lands in M3, the Leptos playground in M9.
::

`wasm32-unknown-unknown` has nothing to read synchronously, so either embed the files with `files()` or
load them over the network with `remote` + `ensure_async`:

```rust
let i18n = I18n::builder().remote(MANIFEST).locale("de").build()?;
i18n.ensure_async("de", Some("settings"), |path| async move {
    gloo_net::http::Request::get(&format!("/locales/{path}")).send().await?.binary().await
}).await?;
```

The crate pulls in no `web-sys` and no HTTP client: the network is yours.

- Time: `Date.now()`; local zone from `Date.getTimezoneOffset()`, named zones through `Intl`.
- `scope().wrap()` works with `wasm-bindgen-futures`.

## Size

Measured as `.wasm` after `wasm-opt -Oz`. Targets for v1: micro build ≤ 40 KB; with `format` and three
locales ≤ 120 KB; the browser `tz` backend adds ≤ 10 KB. The real numbers go to
[Performance](/performance); CI fails on growth over 2%.
