---
title: Tauri guest
description: A Rust frontend (Leptos, Yew, Dioxus) inside Tauri, connected to the plugin.
---

::note
Lands in M9.
::

The `tauri-guest` feature is guest-js for frontends written in Rust:

```rust
let i18n = i18n_next::tauri_guest::connect().await?;   // same payload as the JS package
i18n.install()?;                                        // then t!("key") in components
i18n_next::tauri_guest::set_page("settings").await?;
i18n_next::tauri_guest::set_locale("de").await?;       // Rust backend and every window
```

- Data comes over the same `i18n-next://` protocol through `fetch` from `js-sys`, without `web-sys`.
- The payload format lives in the crate (`payload::encode` for the plugin, `payload::apply` for the
  guest), so both sides share one implementation.
- The `changed` event is heard through `__TAURI_INTERNALS__`, as `@tauri-apps/api` does.
